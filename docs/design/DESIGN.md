# PESDac Design — Study Assistant UI

Theme: `gothic` (deep blue-grays, dark, editorial). Simple dark ChatGPT-style chat with 6-subject sidebar.

Structure: Astro + Astryx (`ChatLayout`, `ChatComposer`, `SideNav`). Manual / auto-detect toggle. Screenshot cards for slides/video keyframes. Easy to restyle via tokens (`--spacing-*`, `--color-*`).
